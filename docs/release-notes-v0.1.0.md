# PeerCall v0.1.0

PeerCall v0.1.0 is the first open-source polish release focused on making the project easier to inspect, reuse, and contribute to.

## Highlights

- English-first UI and documentation.
- Clearer microphone, connection-code, and WebRTC status messaging.
- PWA manifest and service worker improvements.
- Simple mode for larger controls and fewer technical details.
- MIT license, contributing guide, security policy, roadmap, and QA checklist.
- Static smoke tests with GitHub Actions CI.

## Known Limits

- Audio only.
- Manual code exchange.
- No bundled TURN relay, so restrictive networks may fail.
- Mobile browser behavior still needs broader testing.
