How the code exchange works
  • The person who starts the call selects "I start the call", allows the microphone, creates a code, and sends it to the other person.
  • The person answering selects "I answer a call", pastes that code, creates an answer code, and sends it back.
  • The starter pastes the answer code and clicks "Use their code". The browser connects the audio call directly where the network allows it.
  • Codes are one-time setup data for the current call. Share them privately.
